# banking-api-testing-suite

This project demonstrates how to build and test a simple banking API using Python, `pytest`, and the `requests` library. It simulates common banking operations and tests their functionality through automated test cases.

---

##  Features

- Mock banking API with endpoints for:
  - Account creation
  - Deposits
  - Withdrawals
  - Balance inquiries
- Automated tests using `pytest`
- Test reports and detailed response validation
- Easily extendable to support authentication and real databases
