#  banking-api-testing-suite

This project showcases how to **build and test a mock banking API** using Python, `pytest`, and the `requests` library. It simulates core banking operations — like creating accounts, making deposits/withdrawals, and checking balances — while teaching best practices for **automated API testing**.

Whether you're a beginner learning how APIs work or a tester wanting to automate test scenarios, this suite is a solid starting point.

---

##  Features

-  **Mock Banking API** built using Flask, with endpoints for:
  - ✅ Account creation
  - 💰 Deposits
  - 💸 Withdrawals
  - 📊 Balance inquiries

- 🧪 **Automated Testing** with `pytest`:
  - Fast and readable test cases
  - Covers both valid and invalid input scenarios
  - Checks status codes, response messages, and data integrity

- 📈 **Test Reporting & Validation**:
  - Clear output for each test case
  - Edge case coverage and error handling

- 🔌 **Easily Extendable**:
  - Add authentication, real database support, or CI/CD integration
  - Great foundation for real-world API testing projects
